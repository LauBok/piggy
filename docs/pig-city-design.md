# 猪猪城设计方案

> 这是第二阶段「把小窝改造成猪猪城」的设计稿，只有设计，没有代码。

## 总原则

- 所有改动都在 `src/renderer` 里，不改 `main.js`、preload，也不提高 `shellApi`，所以每个阶段都能通过内容热更新上线。
- 小窝窗口保持 900×690、不能缩放。可用区域 876×666：顶部 HUD 占 52，下面地图可视区约 876×614。
- 小窝仍然只是视图：收到状态快照、发回动作。猪在地图上的位置完全由快照里的 `s.activity` 推出来，不存档。
- 存档只新增 `s.npc` 一个字段。`migrate()` 本来就会把旧存档和默认值合并，所以不用提高 `SAVE_VERSION`。

### 1.2 怎么逛

- 只有一张大地图：鼠标拖动或滚轮平移，不能缩放，没有标签页，也没有小地图。
- 点一栋建筑，右侧滑出这栋建筑的面板（宽约 400），左边仍然看得到地图，猪会走过去。学校科技树和小游戏需要大地方，用接近全屏的面板，同时把地图调暗。按 Esc 或点地图空白处关闭。
- 建筑上不写字，只有一个招牌 emoji；鼠标悬停时才冒出一个小名字胶囊。
- 还没解锁的建筑是灰色的，角上标 🔒 和等级（比如大学 🔒18），所以前期地图看起来自然就简单。
- HUD 本身就是导航：点一个变红的状态环，镜头会移到能解决它的地方。
  - 饱食 → 食堂或面包房
  - 清洁 → 家里的浴缸或泡泡屋
  - 健康 → 诊所
  - 体力 → 家
  - 心情 → 公园

### 1.3 HUD（顶部一行，在哪都显示）

```
[猪脸头像 Lv环] 🍖◯ 🧼◯ ⚡◯ 💗◯ 😊◯   [📦 ▓▓▓░ 12:30 ✕]   🪙 1234  🎒  ⚙️  ─ ✕
```

- **头像**：用现有的 `PIG_SVG`，裁成只剩脸（viewBox 和迷你模式一样，`18 2 124 108`），外面一圈是经验环。
- **活动胶囊**：只在小猪忙的时候出现，显示活动图标、进度、剩余时间和取消按钮 ✕。点胶囊，镜头会飞到猪那里。
- **🎒**：打开底部的背包抽屉，一排图标加数量，点一下就用。
- **⚙️**：打开设置面板，包括更新、版本、跟随、迷你、重置和退出。
- **点地图上的猪**：弹出一圈图标，有 🤸 玩耍、😴 睡觉 / ☀️ 起床；忙的时候多一个 ✕。

## 2. 城里的猪

### 2.1 猪在哪里（全靠推算，不存档）

```
placeOf(snap):
  study → 按学段去小学 / 中学 / 大学
  work  → JOB_SCENES[id].place
  help  → 食堂 / 诊所
  hobby → 弹琴、画画在家；踢球在球场
  bath / sleep → 家
  空闲  → 最后打开过的那栋建筑（只是视图状态，不存档）；没有就在家
```

- 地点一变，猪就沿路网用 BFS 找路走过去。速度约 140 px/秒，单程控制在 0.6～4 秒。用 `el.animate()` 实现，配合现成的 `.walking` 腿部动画。
- 窗口刚打开时，猪直接出现在该在的位置，不播走路动画。
- 镜头只在活动刚开始的那一刻跟过去，之后不再抢镜头。

### 2.2 两种呈现方式

1. **户外活动**直接画在地图上：发传单、送报、送快递、拱松露、工地、球场、舞台、湖边、温泉、记者。
2. **室内活动**用「剖面气泡」：在建筑上方浮出一个约 200×130 的圆角小窗，里面画室内场景。用于上学、洗碗、收银、医院、办公室、家里、食堂和诊所。

### 2.3 用道具表示进度

除了 HUD 里的进度条，每个场景里的道具也会跟着 `snap.progress` 变化：

- 传单越发越少，盘子越摞越高，篮子越装越满，箱子越送越少。
- 沿路线移动的工作，猪的位置就是 `route(progress)`。关掉小窝再打开，猪还在原来的位置。
- 位置每秒更新一次（跟着快照），配合 CSS 的 `transition: transform 1s linear`，看起来是连续移动的。

### 2.4 四种场景模板（34 份工作全部套用）

| 模板 | 动作 | 适用的工作 |
|---|---|---|
| `stand` | 站在固定位置，循环做一个动作，手里拿着道具 | 收银、讲解、家教、老师、银行、程序员、律师、设计师、医生、院长、教授、实验员、助教、首席、艺术家、科学家、架构师、基金经理 |
| `patrol` | 在两点之间来回走 | 发传单、记者（拿话筒）、温泉导游（举小旗，后面跟着几只小鸭游客）、体育教练（后面跟着几只小动物） |
| `route` | 按进度沿路线前进，途中有几个停靠点 | 送报员、快递员 |
| `haul` | 在 A、B 两点之间来回搬，一边的堆变少，另一边变多 | 拱松露、洗碗工、砖房小工、球童（捡球放进球筐） |

### 2.5 重点场景（前期最常见的五份工作）

- **发传单**：在商业街人行道上，从面包房门口到服装店门口。猪左右晃动约 40px，手里拿着一叠白纸（5 张，随进度减少）。路人小动物沿着 CSS `offset-path` 循环走过；有路人经过时，猪抬手，一张纸飞过去。偶尔有人不理它，猪就闪过一个难过的表情。时不时冒出 💦。
- **送报员**：从 📦 快递站出发，骑自行车（车轮复用 `.wheel` 的转动动画），经过小猪巷的 8 户人家。每到一户门口，报纸沿弧线落到台阶上。车筐里的 📰 数量就是还剩几户。
- **洗碗工**：🍜 餐馆后巷的剖面气泡。猪站在蓝色水槽前，泡泡复用 `ACCESSORIES.bath` 里的 `.soap`。左边的脏盘子越来越少，右边的干净盘子越来越多并闪 ✨，猪手里的盘子在转。
- **拱松露**：在 🌲 松露林。新增一个 `.dig` 姿势：低头快速点头，带着泥土颗粒。每隔一个循环冒出一个 🍄，飞进篮子，篮子越来越满。身上变脏的程度直接由快照里的 `clean` 决定，这份工作掉清洁快，`#dirt` 的透明度会自然变高。
- **快递员**：从快递站出发，黄色小电驴上叠着 5 个 📦。沿途 5 个停靠点，分布在家具城、写字楼、大学、小猪巷和医院。每到一站，猪下车把箱子交给门口的 NPC，NPC 挥手冒 ♥。

### 2.7 上学、吃饭、看病、在家

- **上学**：学校楼上出现剖面气泡。黑板上是科目或专业的图标，猪坐在课桌前，戴着 `ACCESSORIES.study` 的学士帽。咕咕校长时不时用教鞭敲敲黑板，`BUSY_FX` 里的 💡、✏️ 照常冒出来。
- **食堂**：嘎嘎给猪打饭，猪用 `dining` 姿势吃 🍱。
- **诊所**：猪躺在病床上，头上敷着冰袋（`icebag`），绵绵医生拿着听诊器。
- **在家**：睡觉、洗澡、弹琴、画画都在家的剖面图里，猪站到对应的家具旁边。睡觉时，地图上这栋房子的窗户变暗，烟囱里飘出 zzz。

### 3.1 怎么互动（没有长对话）

- **点 NPC**：头上冒出一个小气泡，只有一个 emoji 加 2～6 个字，比如「早呀🌞」。每天第一次点：好感 +1♥，心情 +2。
- **心愿**：每天由 `hash(日期 + npcId)` 选出 3 个有心愿的 NPC，头上的气泡显示一件想要的物品。物品故意选别家店卖的东西，引导玩家满城逛。背包里有这件东西时气泡会发亮，点一下就送出去：物品扣掉，好感 +2♥，心情 +5。（已定：只给好感，不给金币。）
- **好感度**：0～10♥，显示在头像旁边。5♥ 解锁一个好处，10♥ 在 TA 的店里解锁一件专属商品，这也是后期的花钱去处。好感度不会下降。
- **站位**：第一版里 NPC 固定站在自己店门口。另外有大约 4 个不能互动的路人在路上循环走动，让城里看起来热闹。

### 3.2 需要改的规则（都在 renderer 里）

- `state.js`
  - 新增 `npc: {}`，格式 `{ [id]: { h, hi, wish } }`，其中 `hi` 和 `wish` 是日期字符串。
  - 新增 `Game.greet(id)` 和 `Game.give(id)`。
  - `buy()` 改成按 `priceOf()` 扣钱。
- `rules.js`：新增 `npcWish(id, date)`、`hearts(s, id)`、`npcPerk(s, key)`、`priceOf(s, it)`，两个窗口共用。
- `app.js`：`act()` 新增 `'greet'` 和 `'give'`。
- 各个好处在对应的地方读 `npcPerk`：`help()`、爱好和玩具、`tick` 里的学习经验、`jobPay` 的结果、`PLAY_EXP_DAILY`。

### 3.3 怎么画

- 一个 `animalSvg(species)` 函数，套用猪的 160×150 模板（身体、头、手脚都是椭圆），眼睛直接用 `eyeSvg`。
- 每个物种只换几样东西：
  - 耳朵：`long` / `tri` / `round` / `floppy` / `tuft` / `none`
  - 嘴鼻：`nose` / `beak` / `muzzle`
  - 花纹：熊猫眼、浣熊面罩、龟壳
  - 一套配色
- 全部用纯色，描边 1.5，和猪一致。在地图上缩到 0.3 倍，按物种缓存。

## 4. 猪猪的家

### 4.1 房子分四档

家具不能自由摆放：每件都有固定位置，买了自动出现。

| 档 | 怎么获得 | 外观 | 室内 |
|---|---|---|---|
| 0 小猪窝 | 默认就有 | 圆顶小屋 | 一间：床、浴缸、书桌，2 个装饰位 |
| 1 温馨公寓 | `house1`（20000，已经有） | 两层小楼，带阳台 | 两间：多了沙发、琴、画架，5 个装饰位 |

## 5. 技术方案

### 5.1 用 DOM + SVG，不用 canvas

- 能直接复用 `PIG_SVG`、`renderFace`、`applyForm`、`renderWear` 和 pig.css 里的各种姿势。
- 点击检测是现成的，高分屏也清晰，空闲时完全不占 CPU。
- 和现在用模板字符串拼 HTML 的写法一致。

页面结构：

```
#viewport (overflow:hidden)
  #world (transform: translate3d(-camX,-camY,0); will-change: transform)
    <svg id="cityBase">   地面、道路、各区底色、树、路灯和所有建筑（静态，只生成一次）
    #bubbles              剖面气泡
    #actors               猪、NPC、路人、场景道具（各自是一个绝对定位的小 SVG）
#hud
#sheet                    右侧面板、接近全屏的面板
#drawer                   背包抽屉
```

### 5.2 怎么画建筑

- 一个 `facade({w, h, body, roof:'gable'|'flat'|'dome'|'awning', roofColor, windows:[行, 列], sign:'🍞', extra})` 函数生成所有建筑。
- 配色用马卡龙色系：粉、奶黄、薄荷、雾蓝、淡紫；商店加条纹遮阳篷。
- 招牌用 SVG `<text>` 里的 emoji，和现在界面的 emoji 风格统一。
- 树、花、路灯用固定的随机种子撒，每次打开都长得一样。阴影直接画椭圆。
- 不用 SVG filter 和 drop-shadow，渐变只留在猪身上。
- 鼠标悬停时，建筑的 `<g>` 加上 `transform-box: fill-box; translateY(-3px)`，微微抬起。

### 5.3 动画

- 循环动作（呼吸、摇尾巴、路人走路）用 CSS keyframes，路人走路用 `offset-path`。
- 一次性的走路用 WAAPI，关键帧根据路径算出来。
- 和进度挂钩的位置每秒更新一次，配合 1 秒的 transition。
- 同时在动的元素控制在约 15 个，只改 transform 和 opacity。
- 窗口不可见（`visibilitychange`）时，body 加 `.paused` 类，暂停所有动画（`animation-play-state`）。窗口最小化后 Chromium 也会自动降频。

### 5.4 小窝仍然只是视图

- 地图只生成一次。每次收到快照，只更新这些：猪的位置和场景、建筑上的锁和小红点、NPC 的心愿气泡、HUD。
- 面板沿用现在 `structKey` 的做法，key 里加上 `sheet`。
- 原来 `PAGES` 里的代码大多搬进对应的面板：商店变成 `shop(cat)`，学校变成 `school(stageGroup)`，另外新增招工板、棋亭、家、设置。
- 所有修改状态的操作仍然通过 `window.home.act` 发出。

### 5.5 要小心：SVG 渐变 id 重名

- `PIG_SVG` 里的渐变用了固定 id（比如 `gHead`），而页面上会同时出现两只猪：HUD 头像和地图上的猪。
- `url(#gHead)` 会指向文档中第一个同名定义；如果那个所在的 SVG 被 `display:none` 隐藏，另一只猪的渐变就全没了。
- 解决办法：把渐变 `<defs>` 挪进一个永远不隐藏的 0×0 SVG，或者保证第一只猪永远不被隐藏。
- `renderFace` 这些函数本来就是在各自的根元素内查找，所以不受影响。
